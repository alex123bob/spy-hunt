# Bot Minds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let players shape a bot's mouth (wordiness, form) and mind (thinking level, suspicion, spy reaction), and make default bots self-check whether their word fits the table.

**Architecture:** New outfit fields are validated in `outfits.py`, stored in a new `custom_bots.mind_json` column (the room copy already stores the whole outfit in `players.outfit_json`), turned into prompt lines and a thinking plan by a new pure module `minds.py`, and applied inside `bots._run_describe` / `_run_vote`. Arena and puzzle code never call those two functions, so they are unchanged.

**Tech Stack:** Python/Flask/SQLite/pydantic (backend `ai_svc/spy_hunt`, tests with pytest in `tests/`), React + TypeScript + vitest (frontend `src/`).

**Spec:** `docs/superpowers/specs/2026-11-20-bot-minds-design.md`

## Global Constraints

- A bot never learns its role or another seat's word. The analysis prompt is built from `bots.public_view` only.
- Reaction lines name other players by seat number only, never by name.
- Defaults: `words=3`, `form="plain"`, `think="instinct"`, `suspicion=3`, `reaction="blend_in"`. Missing fields mean these defaults (stored outfits play as today).
- `form` values: `plain, riddle, rhyme, one_word, emoji_only, no_adjectives, question_only`. `think`: `instinct, careful, deep`. `reaction`: `blend_in, go_vague, mirror, deflect`. `words` and `suspicion`: integers 1 to 5. Anything else gives `400 bad_outfit`.
- Max tokens by `words` 1..5: 80, 100, 120, 160, 200 (3 equals today's `STATEMENT_MAX_TOKENS = 120`).
- Spy hunch needs at least 3 statements from other players in the current game. Fit threshold by `suspicion` 1..5: hunch when `fit` is under 20, 30, 40, 50, 60.
- `careful` adds no model call. `deep` adds one analysis call with a 5 second timeout and falls back to `careful` on failure, and when `llm.budget_fraction_left(room_id) < 0.4`.
- Built-in bots use `careful`, suspicion 3, `blend_in`, never `deep`. Built-in bots are built from code, so no migration.
- `statement_max_chars` stays 120 and the own-word check in `game.submit_statement` is unchanged.
- zh-Hans and en text for every new label.

## Review Focus

- First speaker or early seats (fewer than 3 other statements): no hunch, bot speaks as today.
- Model returns JSON without `fit`/`notes`, or `fit` is not a number: bot speaks normally, no crash.
- Analysis call raises (`LlmError`, `BudgetExceeded`, timeout): turn continues as `careful`; no stall.
- `emoji_only` / `one_word` output survives `game.submit_statement` (not turned into a canned line by a length rule).
- A stored outfit or bot with none of the new fields loads, plays and renders as before; an unknown value in a stored `mind_json` is ignored, not fatal.

### Task 3: `minds.py` pure functions

**Files:**
- Create: `backend/ai_svc/spy_hunt/minds.py`
- Test: `backend/ai_svc/spy_hunt/tests/test_minds.py`

**Interfaces:**
- Consumes: `outfits.clean_mind`.
- Produces:
  - `@dataclass(frozen=True) Plan(think: str, max_tokens: int, lines: tuple[str, ...], suspicion: int, reaction: str)`
  - `plan(outfit: dict | None, budget_fraction: float) -> Plan` (`outfit=None` is a stored-nothing custom bot: instinct, 120 tokens; deep drops to careful when `budget_fraction < 0.4`)
  - `BUILTIN_PLAN: Plan` (careful, suspicion 3, `blend_in`, 120 tokens, no lines)
  - `length_line(words: int) -> str`, `form_line(form: str) -> str` (empty string for `plain`; `one_word` and `emoji_only` also replace the length line)
  - `reaction_line(reaction: str) -> str`
  - `evidence_ok(view: dict) -> bool` (at least 3 statements by seats other than `view["my_seat"]`)
  - `hunch(fit: Any, suspicion: int, view: dict) -> bool` (False when `fit` is not an int or float, is a bool, or `evidence_ok` is false; else `fit < 10 + 10 * suspicion`)
  - `analysis_prompt(view_block: str) -> str` and `class AnalysisOut(BaseModel)` with `fit: Optional[float] = None`, `suspects: list[int] = []`, `note: str = ""`
